# Frontline e-Catalog — Demo

For the e-catalog we discussed in the meeting, I’ve put together a very rough draft demo that turns the frontline e-catalog concept into something you can actually use — a tablet sales catalog to browse Sales Kits, link out to 自在購 and eShop product pages, and preview a simple inventory display concept (live pricing from eShop where linked).

Search works from the homepage across all folders, or inside a folder for that area only — try keywords, or filter by product, brand, colour, style, or estate.

We can share it with relevant users so you can try it firsthand and tell me how it feels. That feedback will help us define clearer, more accurate requirements before we build further. Please try it on a tablet if you can: **https://pr-frontline-ecatelog.vercel.app**. Sample data only.
